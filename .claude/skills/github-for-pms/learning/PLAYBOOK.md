# Playbook

Standing rules for this project, earned the hard way. Promoted from
`LEARNING-LOG.md` after a lesson recurred 3+ times.

**These rules override the skill's defaults.** Read this file at the start of any
session in this repo — the project's own hard-won lessons beat generic best practice.

---

## How a rule gets here

1. A lesson is logged in `LEARNING-LOG.md` after a loop closes.
2. `capture_learning.py --review` flags a theme seen 3+ times.
3. The rule is written here, with the evidence linked.
4. The PM is told it's now standing policy.

A rule that stops being true gets struck through with a date and a reason — not
deleted. Knowing what you used to believe is part of the record.
